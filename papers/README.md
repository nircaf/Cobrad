# AI Instructions

Only put finished scientific papers in this folder, as `.pdf` files.

No drafts, no other file types, no supporting scripts/data.

## Manuscript requirements

| **Manuscript Basics** | **Requirement** |
| --- | --- |
| **Subject Area** | Select the subject area most appropriate to the manuscript. |
| **Title** | Enter the manuscript title. |
| **Abstract** | Include the abstract in the uploaded manuscript file. When pasting from a word processor, replace special formatting or symbols with the appropriate special-character codes. |
| **Author Approval** | State that all authors have seen and approved the manuscript. |
| **Competing Interests** | Disclose all potential competing interests; explicitly state when none exist. |
| **Declarations** | Answer all declaration questions. |
| **Data Availability Statement** | Include a statement describing the availability of all data referred to in the manuscript. When pasting from a word processor, replace special formatting or symbols with the appropriate special-character codes. |
| **Data Availability Links** | Enter all pertinent URLs. |
| **Clinical Protocols** | Enter information about the protocols used to perform the work. |

## Authors

- Enter the required information for every author using **Add Author**, or use **Import Authors** and follow the instructions.
- Link each author to an ORCID by entering the ORCID manually or searching by name.
- Use the icons beside each author to reorder, edit, or delete entries.
- Click **Save/Continue** before leaving the page to avoid losing changes.

## Files

### Manuscript file

Submit either a single PDF or separate text and figure files, from which the submission system will create a PDF. Word and PDF are preferred. LaTeX manuscripts should be submitted as PDF; the `.tex` source may be included as supplementary data.

Use only Times, Times New Roman, Courier, Helvetica, Arial, or Symbol fonts to ensure that the generated PDF remains readable.

### Images and tables

Accepted image and table formats include GIF, TIFF, EPS, JPEG, and PowerPoint. Size figures to fit a regular printed page and label every uploaded image file. Most common word-processing formats are accepted for tables.

Unsupported formats include OLE-embedded files, BMP, PICT, Excel (`.xls`), Photoshop (`.psd`), Canvas (`.cnv`), CorelDRAW (`.cdr`), and locked or encrypted PDFs.

Uploaded images are converted to PDF and appended to the manuscript. For an initial submission containing a complete PDF with embedded images, separate image files are unnecessary. All primary/source files will be required at revision.

### Supplemental files

Select the supplemental-file option for data supplements and label every supplemental file. Supplemental files are not converted to PDF.

Filenames must not contain symbols or punctuation other than hyphens, underscores, and file-extension periods.

Ensure that Word `.txt` files use Unicode or UTF-8 encoding to avoid conversion problems.
